# 🚀 SEO Toolkit

A modern **full-stack SEO toolkit** that helps users analyze websites, research keywords, optimize content, compare competitors, and generate AI-powered SEO content briefs.

Built with a focus on **clean UI, real-time analysis, practical SEO insights, and AI-powered content planning**.

---

## ✨ Features

### 🔍 Website Analyzer

* Analyze any website URL
* SEO score with detailed breakdown
* Title & meta description check
* Heading structure analysis (H1, H2, H3)
* Image alt text audit
* Internal & external link analysis
* Broken links detection
* Keyword density analysis
* Page load time measurement
* Actionable SEO suggestions

---

### ✍️ Content Optimizer

* Optimize blog/article content using a target keyword
* Keyword density calculation
* Keyword position check (first 100 words)
* Content length analysis
* Heading structure detection
* SEO score with suggestions
* Keyword highlighting inside content
* Visual progress indicators

---

### 📈 Competitor Analysis

* Compare your website with a competitor
* Side-by-side SEO comparison
* SEO score comparison
* Meta title & description comparison
* Heading structure comparison
* Image optimization comparison
* Internal & external link comparison
* Keyword density comparison
* AI-powered recommendations
* Visual winner indicators

---

### 🔑 Keyword Research

* Analyze any target keyword
* Search volume estimation
* Keyword difficulty score
* Cost-per-click (CPC) estimation
* Competition level
* Related keyword suggestions
* Long-tail keyword ideas
* Search intent insights
* SEO opportunities

---

### 🤖 AI SEO Content Brief

Powered by **Google Gemini 2.5 Flash**

* Generate complete SEO content briefs
* Search intent analysis
* Target audience identification
* Content goal suggestions
* SEO title generation
* Meta description generation
* SEO-friendly URL slug
* Recommended word count
* H1, H2 & H3 outline generation
* Related keywords
* Long-tail keyword suggestions
* FAQ generation
* Internal linking ideas
* SEO writing guidelines
* Call-to-action generation
